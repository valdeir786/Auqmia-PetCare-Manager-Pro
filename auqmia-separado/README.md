# Auqmia – PetCare Manager Pro

Primeiro projeto acadêmico de desenvolvimento web.

## Tecnologias
- HTML5
- CSS3
- JavaScript

## Como executar
Abra o arquivo `index.html` em um navegador. Para uma experiência melhor durante o desenvolvimento, você pode usar a extensão Live Server do Visual Studio Code.

## Estrutura
- `index.html`: estrutura e conteúdo da aplicação.
- `style.css`: estilos e responsividade.
- `script.js`: funcionalidades e interações.

## Observação
Este projeto é um protótipo front-end. Os dados são mantidos no próprio JavaScript e não há integração com servidor ou banco de dados.
