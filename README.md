# 🐾 Auqmia – PetCare Manager Pro

**Meu primeiro projeto acadêmico | Desenvolvimento Web**

Site:https://valdeir786.github.io/Auqmia-PetCare-Manager-Pro/

## 📌 Sobre o projeto

O Auqmia – PetCare Manager Pro foi meu primeiro projeto acadêmico desenvolvido durante a graduação em Análise e Desenvolvimento de Sistemas na UNICID.

O projeto surgiu como uma oportunidade de dar meus primeiros passos na área de desenvolvimento de software, colocando em prática os conhecimentos iniciais adquiridos durante minha formação.

A proposta foi desenvolver um sistema web para gerenciamento de um pet shop, reunindo diferentes funcionalidades administrativas e comerciais em uma única aplicação.

## 🎯 Objetivo

Desenvolver uma aplicação que facilitasse a organização e o gerenciamento de um pet shop, explorando conceitos fundamentais de programação, desenvolvimento web e experiência do usuário.

## ⚙️ Funcionalidades desenvolvidas

- **Dashboard:** visualização de indicadores e informações gerais.
- **Frente de vendas:** catálogo de produtos e simulação de compras.
- **Controle de estoque:** cadastro e gerenciamento de produtos.
- **Agendamentos:** organização de serviços e atendimentos.
- **Gestão de clientes:** cadastro e consulta de informações.
- **Relatórios:** visualização de informações financeiras e operacionais.
- **Área do cliente:** consulta de histórico e agendamentos.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## 📚 O que aprendi com este projeto?

Por ser meu primeiro contato prático com o desenvolvimento de sistemas, este projeto representou uma etapa importante da minha trajetória acadêmica.

Durante seu desenvolvimento, pude conhecer e aplicar conceitos como:

- Estruturação de páginas com HTML.
- Estilização de interfaces com CSS.
- Lógica de programação com JavaScript.
- Manipulação do DOM.
- Utilização de funções, condições e estruturas de repetição.
- Organização de elementos e funcionalidades de uma aplicação web.
